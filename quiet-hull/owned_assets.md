## How to complete this list from the Asset Store

Claude can't reach a logged-in browser from a cloud session. To export the full list yourself:

1. Open https://assetstore.unity.com/account/assets in Chrome while logged in.
2. Open DevTools (F12) → **Console**, paste the snippet below and press Enter. It copies the packages on the current page to your clipboard.
3. Go to **page 2** (and any further pages), run it again, and paste every result into the chat.

```js
(() => {
  const byId = new Map();
  document.querySelectorAll('a[href*="/packages/"]').forEach(a => {
    const url = a.href.split(/[?#]/)[0];
    const id = (url.match(/-(\d+)$/) || [])[1];
    if (!id) return;
    const name = (a.textContent || a.getAttribute('title') || a.getAttribute('aria-label') || '').trim().replace(/\s+/g, ' ');
    const prev = byId.get(id);
    if (!prev || (!prev.name && name)) byId.set(id, { name, url });
  });
  const lines = [...byId.values()].map(p => `${p.name || '(no title)'} | ${p.url}`);
  console.log(`${lines.length} packages on this page\n` + lines.join('\n'));
  copy(lines.join('\n'));
})();
```

The snippet only reads links already on the page. It changes nothing and sends nothing anywhere.
